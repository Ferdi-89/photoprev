# Panduan Template Desain Foto Strip (Photobooth Frame)

Folder ini digunakan untuk menyimpan template desain bingkai foto strip (*photobooth frames*).

## Spesifikasi Format File Desain Sendiri
1. **Format File**: PNG dengan transparansi (*PNG-24 dengan Alpha Channel*).
2. **Ukuran Standar**:
   - **Double Strip pada Kertas 4R (Paling Umum)**: `1200 x 1800 piksel` (300 DPI). Berisi 2 kolom strip 600x1800 px berdampingan.
   - **Single Strip 2x6 Inci**: `600 x 1800 piksel` (300 DPI).
3. **Area Foto**: Buat kotak lubang foto dalam keadaan **transparan/bolong (cutout)**. Foto pelanggan akan diletakkan oleh sistem di bawah lapisan desain ini.
4. **Area Bingkai & Teks**: Isi pinggiran dan bagian bawah dengan nama studio, logo, tanggal, atau ornamen acara.

## Cara Menggunakan
* **Lewat Browser**: Buka Dashboard Operator -> Menu Template Foto Strip -> Upload File PNG.
* **Lewat Windows Explorer**: Salin file PNG desain ke folder `templates/custom/`. Sistem akan langsung mendeteksinya secara otomatis.
